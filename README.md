# Мои первые проекты на C++

Здесь я изучаю основы C++ и выполняю учебные задания.

## Что я уже изучила

- переменные и типы данных;
- ввод и вывод: `std::cin`, `std::cout`;
- условия `if / else`;
- циклы `for` и `while`;
- простые консольные программы.

## Примеры программ

- калькулятор;
- определение возраста;
- таблица умножения;
- игра «Угадай число»;
- проверка пароля.

## Цель

Научиться создавать понятные и полезные программы на C++.
